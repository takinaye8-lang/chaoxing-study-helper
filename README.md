# 网课助手（安全低速版） - 超星学习通

> 市面上的刷课工具在比谁快，这份脚本在比谁稳。

本项目是一个基于 Tampermonkey 的用户脚本（UserScript），专为**超星学习通**设计。它不追求“几小时刷完”，而是通过刻意放慢节奏、限制倍速、遇风控即停等策略，最大程度降低账号触发平台风控的概率。

## 🛡️ 核心特性（为什么选择这个脚本？）

- **零联网，不碰凭据**：没有题库，没有 API 请求，没有任何跨站网络出口。你的页面内容、账号密码绝不会离开你自己的浏览器。
- **限速保守**：播放倍速硬上限锁死 `1.25x`，点击间隔 `3-5秒` 随机，阅读停留 `2.5-4秒/屏`，规避机械行为特征。
- **遇风控即停**：检测到验证码、人脸、滑块或“异常操作”提示，立即暂停且不自动恢复；连续两次触发直接锁定本页。
- **本地可审计**：纯前端逻辑，无混淆，无隐藏代码。

## ⚠️ 功能边界（它不做什么）

请仔细阅读以下限制，**不要期待它是一款全自动全能工具**：
1. **不做题**：不提供题库、不填答案、不自动提交。章节测验仅做“点击右侧目录跳过”处理。
2. **不支持智慧树**：当前版本仅支持超星学习通（`mooc1/2.chaoxing.com` 等），智慧树模块尚未校准。
3. **不保证绝对不被封**：风控机制在暗，脚本在明。本脚本仅通过降低频率来降低风险，无法提供 100% 免封保证。

## 📦 安装方法

1. 确保你的浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）扩展。
2. 点击下方链接安装本脚本：
   👉 **[点此安装脚本 (Raw 链接)](https://raw.githubusercontent.com/takinaye8-lang/chaoxing-study-helper/main/chaoxing-study-helper.user.js)** 
3. 安装完成后，打开学习通网课页面，右下角会出现控制面板，打开总开关并点击“启动”即可。

## 🛠️ 已知限制

- `pause → resume` 后，部分媒体事件监听可能丢失，会依靠内部的 2 秒看门狗（watchdog）兜底。
- 跨域 iframe 中的视频唤醒机制尚不完美，部分特殊页面需要手动点击一次播放。
- 平台页面结构随时可能改版，若发现脚本失效，请提交 Issue 或等待更新。
